# BAF706 Personal Finance: bài nhóm Family A

Repo này giữ nội dung dàn ý báo cáo nhóm môn Personal Finance (BAF706, HUB) để làm nguồn cho bài thuyết trình. Bản gốc được viết và sửa trong Claude Docs; repo nhận bản sao Markdown sau mỗi lần nội dung thay đổi.

## Cấu trúc

| Đường dẫn | Nội dung |
|---|---|
| `noi-dung/dan-y-bao-cao-family-a.md` | Toàn bộ dàn ý báo cáo (Part 1–5, phụ lục kiểm tra số liệu), xuất từ Claude Docs |
| `noi-dung/hinh/` | Hình dùng trong dàn ý (biểu đồ tỷ số trước/sau) |
| `THAY-DOI.md` | Nhật ký thay đổi nội dung: mỗi lần đồng bộ ghi ngày, phiên bản doc và các số liệu đã đổi |

## Cách đồng bộ

- Nội dung chỉ sửa ở Claude Docs, không sửa trực tiếp file Markdown trong repo (lần đồng bộ sau sẽ ghi đè).
- Mỗi lần đồng bộ là một commit riêng, kèm một mục mới trong `THAY-DOI.md`. Muốn biết slide nào cần cập nhật, xem mục mới nhất trong `THAY-DOI.md` hoặc `git diff` của commit đó.
- Đơn vị tiền trong toàn bộ nội dung: triệu VND.
