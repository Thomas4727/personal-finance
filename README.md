# BAF706 Personal Finance: bài nhóm Family A

Repo này giữ nội dung dàn ý báo cáo nhóm môn Personal Finance (BAF706, HUB) để làm nguồn cho bài thuyết trình. Bản gốc được viết và sửa trong Claude Docs; repo nhận bản sao Markdown mỗi khi nhóm yêu cầu cập nhật.

## Nguồn dữ liệu cho bài thuyết trình

**`noi-dung/dan-y-bao-cao-family-a.md` là nguồn dữ liệu duy nhất cho bài thuyết trình.** Mọi số liệu, bảng, nhận định và thứ tự nội dung trên slide phải lấy từ file này.

- Không tự thêm hay tự tính lại số liệu ngoài file. Số nào trên slide khác với file là slide sai.
- Khi file thay đổi, xem mục mới nhất trong `THAY-DOI.md` để biết số nào đổi và slide nào cần sửa.
- Đơn vị tiền trong toàn bộ nội dung: triệu VND.
- Gợi ý ánh xạ slide: bảng ba vấn đề (mục 4.1), chi tiêu tháng trước/sau (4.4), so sánh tại 31/12/2027 (4.5), biểu đồ tỷ số trước/sau (`noi-dung/hinh/ty-so-truoc-sau-2027.png`), lộ trình 12 tháng (4.7).
